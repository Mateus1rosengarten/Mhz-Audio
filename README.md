# Event Elevate

Crie um website moderno, premium e minimalista para uma empresa de locação de equipamentos de som, iluminação, DJs e bandas para eventos.

O objetivo principal é transmitir profissionalismo, confiança e incentivar o visitante a solicitar um orçamento pelo WhatsApp. Faça uma arquitetura Senior para o site,separando tudo de forma moderna e  usando componentes reutilizaveis e seguindos as melhores praticas react. use nome de variaveis em ingles e textos so site em portugues

Direção de Design

O resultado deve lembrar o padrão de sites modernos de empresas premium: poucos elementos por seção, excelente hierarquia visual, imagens grandes, bastante espaçamento, animações discretas e foco total na conversão para orçamento via WhatsApp. Evite aparência de site institucional antigo; priorize um visual contemporâneo, sofisticado e elegante mas que não fique template loveable
